## Swap workflow

1. Confirm the affiliate application is approved and the program terms allow this redirect.
2. Open the matching `go/<tool>.html` file.
3. Replace all three `__AFFILIATE_URL__` placeholders with the approved affiliate URL.
4. Keep `noindex, nofollow` and `rel="nofollow"` unchanged.
5. Test both the automatic redirect and the fallback link before publishing.
